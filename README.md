# BIO GAME 10 | زیست‌گیم دهم — فاز ۱
دبیرستان شهید بهشتی، خرامه، فارس · طراح و سازنده: محمد مهدی سیاهزاری · دبیر زیست‌شناسی: آقای حسینی

## اجرا
در پوشهٔ پروژه این دستور را بزنید و آدرس را در مرورگر باز کنید (برای Service Worker و حالت آفلاین، localhost یا HTTPS لازم است):

    python3 -m http.server 8000      →  http://localhost:8000

باز کردن مستقیم index.html هم کار می‌کند، اما حالت آفلاین و نصب PWA فعال نمی‌شود.

## ساختار
- index.html، manifest.json، service-worker.js
- css/style.css — ظاهر، چهار پوسته (تاریک، روشن، طبیعت، آزمایشگاهی) و واکنش‌گرایی
- data/chapters.js — فصل‌ها، گفتارها، نکات آموزشی، نام نشان هر فصل
- data/questions.js — بانک سؤالات (M چهارگزینه‌ای، T درست/نادرست، F جای خالی)
- js/storage.js — ذخیره در LocalStorage و ابزارها · js/quiz-engine.js — موتور آزمون · js/app.js — صفحه‌ها و مسیریابی
- assets/fonts/vazirmatn.woff2 — فونت وزیرمتن (مجوز OFL)، محلی

## افزودن سؤال یا فصل
سؤال جدید را فقط به انتهای آرایهٔ data/questions.js اضافه کنید. شناسه‌ها به ترتیب ساخته می‌شوند؛ حذف یا جابه‌جایی سؤال، پیشرفت ذخیره‌شده را به هم می‌زند. پس از تطبیق هر سؤال با صفحهٔ کتاب، مقدار v را true کنید تا برچسب «پیش‌نویس» برداشته شود. پس از هر تغییر فایل‌ها، نام نسخهٔ V در service-worker.js را عوض کنید.

## قوانین بازی
- هر فصل: آموزش ← تمرین ← نبرد نهایی (زمان‌دار، ۳۰ ثانیه برای هر سؤال)؛ با ۷۰٪ فصل بعد باز می‌شود.
- امتیاز (XP و سکه) فقط برای نخستین پاسخ درست هر سؤال ثبت می‌شود.
- ذخیره‌سازی فقط روی همین مرورگر است و امنیت سمت سرور ندارد.

## وضعیت
انجام‌شده: نقشهٔ ۷ فصل، آموزش، تمرین، نبرد نهایی، آزمون جامع، مرور اشتباهات، XP/سطح/سکه/زنجیره/مأموریت روزانه، نشان‌ها، آمار با نمودار SVG، پروفایل، تنظیمات، درباره.
فاز ۲ (هنوز ساخته نشده): آزمایشگاه مجازی، جورچین، شکار اشتباه، تشخیص تصویر، کلمات زیستی، پنل مدیریت و پشتیبان‌گیری، IndexedDB، سؤالات بیشتر و تطبیق با کتاب.
